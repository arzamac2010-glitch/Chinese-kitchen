# 🇨🇳 Рецепти Китайської Кухні (Chinese Kitchen Recipes)

Веб-додаток (MVP) для любителів азіатської кулінарії. Проєкт дозволяє швидко знаходити автентичні рецепти китайської кухні, додавати улюблені страви до обраного та використовувати вбудований звуковий кухоньний таймер прямо під час приготування.

## 🚀 Функціонал

- **База автентичних рецептів:** Містить детальні покрокові інструкції для відомих страв (Курка Гунбао, Свинина в кисло-солодкому соусі, Мапо Тофу, Смажений рис по-янчжоуськи, Пекінська капуста у воці).
- **Розумний пошук:** Миттєва фільтрація страв "на льоту" за назвою або конкретним інгредієнтом.
- **Вбудований кухонний таймер:** Можливість запустити таймер (на 1, 3 або 5 хвилин) всередині картки рецепту зі звуковим сигналом після закінчення часу.
- **Система "Обране" (Favorites):** Збереження улюблених рецептів у пам'ять браузера (`LocalStorage`) — дані не зникають навіть після оновлення сторінки.
- **Адаптивний дизайн:** Додаток зручно відкривати як на комп'ютерах, так і на екранах смартфонів.

## 🛠️ Технологічний стек

Проєкт створено за принципом чистого вебу (Vanilla Web) без використання важких фреймворків:
- **HTML5** — структура та семантика сторінок
- **CSS3** — стилізація, адаптивна сітка (`Grid layout`) та китайські автентичні мотиви в дизайні
- **JavaScript (ES6+)** — динамічний рендеринг, логіка пошуку, робота з Web Audio API та `LocalStorage`

## 📦 Як запустити локально

1. Складіть усі файли проєкту в одну папку на комп'ютері:
   - `index.html`
   - `style.css`
   - `script.js`
   - `README.md`
2. Двічі клацніть на файл `index.html`, щоб відкрити додаток у вашому улюбленому браузері.

## 🌐 Розгортання (Deployment)

Цей проєкт повністю готовий для безкоштовної публікації через **GitHub Pages**. Для цього у налаштуваннях репозиторію (`Settings` -> `Pages`) увімкніть розгортання з гілки `main`/`master`.
